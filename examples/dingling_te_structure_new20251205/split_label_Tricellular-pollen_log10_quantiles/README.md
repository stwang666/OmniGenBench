# Tricellular-pollen数据提取和三分位点标签划分

## 功能说明

这个脚本用于从原始数据文件中提取`Tricellular-pollen`组织的数据，并根据TE值的三分位点（tertiles）将数据划分为三个类别（0, 1, 2）。

## 使用方法

### 1. 提取Tricellular-pollen数据并划分标签

```bash
python3 extract_tricellular_pollen_triclass.py
```

### 2. 划分训练/验证/测试集（8:1:1）

```bash
python3 split_train_valid_test.py
```

## 输入文件

- `9tissue_structure_te_hc_deseq2_tp_split_log10.csv` - 包含所有tissue数据的CSV文件

## 输出文件

### 第一步：数据提取和标签划分

1. **数据文件**: `9tissue_structure_te_hc_deseq2_tp_split_log10_Tricellular-pollen_triclass.csv`
   - 包含筛选后的Tricellular-pollen数据
   - 新增`label`列，值为0、1或2

2. **可视化图表**: `tricellular_pollen_triclass_distribution.png`
   - 包含数据分布直方图、按类别着色的直方图、箱线图和饼图

### 第二步：数据集划分

3. **训练集**: `train.csv` (80%, 14,877个样本)
   - 每个类别: 4,959个样本 (33.33%)

4. **验证集**: `valid.csv` (10%, 1,860个样本)
   - 每个类别: 620个样本 (33.33%)

5. **测试集**: `test.csv` (10%, 1,860个样本)
   - 每个类别: 620个样本 (33.33%)

**注意**: 使用分层抽样（stratified sampling）确保每个数据集中各类别的比例保持一致。

## 标签划分规则

根据TE值的三分位点进行划分：

- **类别0 (低)**: TE < 33.33%分位点
- **类别1 (中)**: 33.33%分位点 ≤ TE < 66.67%分位点  
- **类别2 (高)**: TE ≥ 66.67%分位点

## 输出数据格式

所有CSV文件包含以下列：
- `GeneID`: 基因ID
- `sequence`: 序列
- `structure`: 结构
- `TE`: TE值（log10转换后）
- `tissue`: 组织类型（全部为"Tricellular-pollen"）
- `label`: 标签（0, 1, 或 2）
