# 结构编码改进说明（中文版）

## 问题1：SPD Bias 的影响方向 ✅

### 问题
在SPD实现中，距离为1的位置相比距离为3的位置，在attention里面数字较大的反而告诉模型的影响更大一些吗？但实际上距离越近更可能形成motif。

### 答案
**当前实现是正确的！** 距离越近，bias越大，这符合生物学直觉。

### 详细分析

#### 当前实现
```python
# 距离 0 (自身): 0.5
# 距离 1 (直接相邻): 0.3  ← 更大的bias
# 距离 2: 0.2
# 距离 3: ~0.09            ← 更小的bias
```

#### Softmax的放大效应
虽然bias的差异看起来不大（0.3 vs 0.09），但softmax的指数性质会显著放大这种差异：

```
假设两个位置的base attention score都是0：
- 位置A（距离1）: score = 0 + 0.3 = 0.3
- 位置B（距离3）: score = 0 + 0.09 = 0.09

Softmax后：
- prob_A = exp(0.3) / (exp(0.3) + exp(0.09) + ...) ≈ 0.55
- prob_B = exp(0.09) / (exp(0.3) + exp(0.09) + ...) ≈ 0.45

差异被放大了！
```

### 改进建议

使用 `ImprovedSPDStructureBias` 类，提供：
1. **更合理的初始化**：距离1的bias = 0.5（而不是0.3），更强调近距离
2. **温度缩放**：可以控制softmax的锐度，避免过度放大
3. **衰减函数选择**：指数衰减或逆函数衰减

## 问题2：配对类型编码 ❌

### 问题
在传入结构信息时，有没有告诉模型对于配对位置的不同情况，比如GC含有三个氢键更稳定、折叠的能量也更高；AU两个氢键这种信息。稳定性不同对TE的影响也不同。

### 答案
**当前实现不包含配对类型信息！**

### 当前实现的问题

当前代码只从**点括号表示法**（如 `"(((...)))"`）提取配对信息：
- ✅ 知道哪些位置配对
- ❌ **不知道**配对的具体类型（GC、AU、GU等）

点括号表示法不包含碱基序列信息，因此无法区分：
- GC配对（3个氢键，最稳定，ΔG ≈ -3.4 kcal/mol）
- AU配对（2个氢键，中等稳定，ΔG ≈ -2.1 kcal/mol）
- GU配对（2个氢键，wobble配对，较不稳定，ΔG ≈ -1.3 kcal/mol）

### 生物学意义

不同配对类型对翻译效率（TE）的影响：

| 配对类型 | 氢键数 | 自由能 | 稳定性 | 对TE的潜在影响 |
|---------|--------|--------|--------|---------------|
| **GC** | 3 | -3.4 kcal/mol | 最稳定 | 结构更稳定，可能影响核糖体结合 |
| **AU** | 2 | -2.1 kcal/mol | 中等稳定 | 平衡的稳定性和灵活性 |
| **GU** | 2 | -1.3 kcal/mol | 较不稳定 | 结构更灵活，可能有利于某些翻译过程 |

### 改进方案

在 `structure_encoding_improvements.py` 中提供了完整的解决方案：

#### 1. 配对类型提取函数
```python
pairing_matrix, pairing_type_matrix, pairing_stability_matrix = \
    dot_bracket_to_pairing_matrix_with_types(
        structure="(((...)))",
        sequence="AUGCAUGC",  # 需要序列信息！
        max_length=512
    )
```

返回：
- `pairing_matrix`: 0/1矩阵，表示是否配对
- `pairing_type_matrix`: 配对类型ID（0=GC, 1=AU, 2=GU, 3=OTHER）
- `pairing_stability_matrix`: 稳定性权重（基于自由能）

#### 2. 配对类型Bias模块
```python
class BasePairTypeBias(nn.Module):
    """
    为不同配对类型分配可学习的bias：
    - GC: bias = 0.5 * scale  (最稳定)
    - AU: bias = 0.3 * scale  (中等稳定)
    - GU: bias = 0.1 * scale  (较不稳定)
    """
```

#### 3. 组合编码
```python
class CombinedStructureBias(nn.Module):
    """
    组合SPD和配对类型编码：
    
    A_ij = (Q_i K_j^T) / √d + b_spatial(SPD_ij) + b_pair_type(pair_type_ij)
    
    同时捕获：
    1. 空间距离信息（SPD）
    2. 配对稳定性信息（GC > AU > GU）
    """
```

### 如何使用

#### 步骤1：修改数据集类
在 `prepare_input()` 中同时读取 `sequence` 和 `structure`：

```python
def prepare_input(self, instance, **kwargs):
    sequence = instance.get("sequence") or instance.get("seq")
    structure = instance.get("structure")
    
    if structure and sequence:
        # 计算配对类型矩阵
        pairing_matrix, pairing_type_matrix, pairing_stability_matrix = \
            dot_bracket_to_pairing_matrix_with_types(
                structure, sequence, self.max_length
            )
        
        tokenized_inputs["pairing_matrix"] = pairing_matrix
        tokenized_inputs["pairing_type_matrix"] = pairing_type_matrix
        tokenized_inputs["pairing_stability_matrix"] = pairing_stability_matrix
```

#### 步骤2：修改模型类
使用 `CombinedStructureBias` 替换原有的 `SPDStructureBias`：

```python
# 原始代码
self.spatial_encoding = SpatialEncodingBias(num_heads, max_distance)

# 改进代码
self.structure_bias = CombinedStructureBias(
    num_heads=num_heads,
    max_distance=max_distance,
    use_pair_type=True,  # 启用配对类型编码
)
```

#### 步骤3：在forward中使用
```python
def forward(self, **inputs):
    spd_matrix = inputs.pop("spd_matrix")
    pairing_matrix = inputs.pop("pairing_matrix", None)
    pairing_type_matrix = inputs.pop("pairing_type_matrix", None)
    pairing_stability_matrix = inputs.pop("pairing_stability_matrix", None)
    
    # 计算组合bias
    structure_bias = self.structure_bias(
        spd_matrix,
        pairing_matrix,
        pairing_type_matrix,
        pairing_stability_matrix,
    )
    
    attn_scores = attn_scores + structure_bias
```

### 数据要求

要使用配对类型编码，CSV文件需要同时包含：
- `sequence` 或 `seq` 列：RNA序列（如 "AUGCAUGC"）
- `structure` 列：点括号表示法（如 "(((...)))"）

确保序列和结构的长度一致！

## 总结

### 问题1：SPD Bias ✅
- **状态**：当前实现是正确的
- **改进**：可以使用 `ImprovedSPDStructureBias` 获得更好的初始化和温度控制
- **影响**：距离越近，bias越大，softmax会进一步放大这种差异

### 问题2：配对类型编码 ❌
- **状态**：当前实现不包含配对类型信息
- **原因**：点括号表示法不包含碱基序列信息
- **改进**：使用 `BasePairTypeBias` 和 `CombinedStructureBias` 来编码GC、AU、GU等配对类型
- **要求**：需要同时提供 `sequence` 和 `structure` 信息
